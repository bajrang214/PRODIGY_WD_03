# 🎮 Tic-Tac-Toe Web App

A clean and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**.

## 🔗 Live Demo

[Play Now](https://bajrang214.github.io/PRODIGY_WD_03/) <!-- Update after deployment -->

## 🧠 Features

- Two-player mode (X vs O)
- Win detection and Draw check
- Restart button
- Clean and responsive layout

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript

## 🚀 How to Play

- Player X starts first
- Click on a cell to mark it
- First to get 3 in a row wins
- Click "Restart" to reset the game
